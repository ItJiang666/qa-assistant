# 干净机器验收清单

> 这份清单是 **P7 的最后一道关**：在一台**没装过本项目**的机器上，
> 只照 `README.md` 走一遍，确认"别人真的能跑起来"。
>
> 为什么必须单独做这一步：开发机上一切"理所当然"的东西（JDK 装好了、Ollama 常驻、
> 模型早拉过、`.env` 早配好、Maven 缓存是热的）在别人机器上**全都不存在**。
> 上面这些缺任何一样，都不会在本机暴露出来。

---

## 0. 验收前提

| 项 | 说明 |
|---|---|
| 目标机 | **没装过本项目**；最好也没装过 JDK 与 Ollama（这样能顺带验前置条件说明是否够用） |
| 材料 | 从 `package-release.cmd` / `package-release.sh` 产出的 zip，与 `README.md` |
| 通过标准 | 全程**只照 README**，不查源码、不问我，能打开页面并得到一次带出处的回答 |

**记录方式**：每项打勾并写下实际观察到的现象；**卡住的每一步都要原样记下来** ——
卡点本身就是 README 的缺陷，比"跑通了"更有价值。

---

## 1. 解压与文件完整性

- [ ] 解压 `qa-assistant-1.0.0.zip` 到任意目录（路径含中文/空格各试一次）
- [ ] 核对 `SHA256SUMS.txt` 里的哈希与 jar 实际哈希一致
      - Windows：`certutil -hashfile qa-assistant-1.0.0-SNAPSHOT.jar SHA256`
      - Linux/macOS：`sha256sum -c SHA256SUMS.txt`
- [ ] 确认解压后**没有** `.env`（不该出现在包里）

---

## 2. 前置条件（README「前置条件」一节是否够用）

- [ ] 未装 JDK 时，`start.cmd` / `start.sh` 是否给出**可照做**的提示（而不是 `UnsupportedClassVersionError`）
- [ ] 装好 JDK 17 后重跑，是否被识别为满足要求
- [ ] 未装 Ollama 时，脚本的提示是否让你明白"要用本地模型得先装 Ollama"（而不是直接崩）
- [ ] 无独显的机器上，启动日志是否出现 `num_ctx 使用保守值 4096` 并建议改用云端模式

---

## 3. 一键启动脚本

Windows：

- [ ] 双击 `start.cmd` 能跑起来（不需要先开命令行窗口）
- [ ] 中文提示**不乱码**（若乱码，检查 `start.cmd` 是否被存成了 UTF-8）
- [ ] 8 秒后浏览器自动打开 `http://localhost:8080`
- [ ] `start.cmd 8081` 能换端口启动
- [ ] 端口被占用时，提示是否说清"换一个端口"

Linux / macOS：

- [ ] `chmod +x start.sh && ./start.sh` 能跑起来
- [ ] 脚本自动开浏览器（有 `open` 或 `xdg-open` 时）
- [ ] `.sh` 换行是 LF（用 `file start.sh` 确认不是 CRLF）

---

## 4. 首次运行（空数据目录）

- [ ] 启动前**确认本机没有** `~/.qa-assistant`（有就先改名备份）
- [ ] 启动后该目录被自动创建，且含 `data/`、`uploads/`、`index/`、`logs/`
- [ ] 系统状态页显示的**数据目录**与实际一致
- [ ] 首次提问能正常回答（本地模式：确认 `qa-embed:4b` 那步是否按 README 做了）

---

## 5. 端到端问答（核心验收）

- [ ] 上传一份自己的文档（docx 或 pdf），状态变为"已入库"
- [ ] 问一个**只有该文档里才有**的答案，回答正确
- [ ] 回答下方的「引用来源」展开后能看到**真实文件名**
- [ ] 问一个文档里**没有**的问题，回答是"未找到"而**不是**编造
- [ ] 连续追问 3 轮，第 3 轮问"我第 1 轮问的是什么"，能答对（会话记忆）
- [ ] 刷新页面后，会话与消息仍在（会话 id 持久化）
- [ ] 新建会话，说"以后回答简短点"，再开**新会话**提问 —— 回答明显变短（长期记忆）
- [ ] 「记忆管理」页能看到那条记忆，删掉后在**新会话**里立刻不再生效

---

## 6. 模式切换（有云端 Key 时）

- [ ] 「模型来源」弹窗里能切到云端，切换后页面自动刷新且页头显示"云端"
- [ ] 云端模式下问一次，回答正常，页头有"数据会发送给云端"的警示
- [ ] 「系统状态」点连通性自检，两个端点都显示通过
- [ ] 把 `.env` 里的 Key 改成错的、重启，再提问 —— 提示应当是
      "模型服务拒绝了当前 API Key（401）…" 而**不是**"系统内部错误"
- [ ] 换回正确 Key、重启，自检恢复通过

---

## 7. 已知不支持的场景（确认提示到位，而不是静默失败）

- [ ] 上传扫描版 PDF → 明确提示"无文字层，需 OCR，本期不支持"
- [ ] 上传 > 50 MB 的文件 → 明确提示超过大小限制
- [ ] 上传不支持的扩展名 → 明确提示不支持的文件类型

---

## 8. 出包脚本

- [ ] 在目标机（或另一台装了 Maven + Node 的机器）执行 `package-release.cmd` / `.sh`
- [ ] 产物 zip 与 `.sha256` 都生成
- [ ] 脚本输出里**没有**"存在敏感文件"的拒绝信息，且包内清单不含 `.env`
